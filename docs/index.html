¿De verdad lo quieres?

Una aplicación web personal para guardar lo que te planteas comprar, imponerte un periodo de reflexión y decidir con calma si lo compras, lo pospones o lo descartas.

Ponerla en marcha Qué hace

Qué hace

Periodo de reflexión

Sugiere una espera según el precio: 7, 15, 30 o 45 días. Puedes ajustarla a mano y configurar los tramos de precio y días desde la propia app.

Cuestionario de revisión

Cuando llega la fecha, respondes 10 preguntas y puntúas necesidad e interés. El historial queda guardado y nunca se sobrescribe.

Recomendación orientativa

Con tu última revisión, la app te orienta sobre si merece la pena: una recomendación, no una decisión automática.

Alternativas y «dupes»

Añade alternativas más baratas y compáralas con el original: diferencia de precio, ahorro, similitud, calidad, durabilidad y garantía.

Inventario

Registra lo que ya tienes. Si vas a comprar algo de una categoría que ya cubres, la app te lo recuerda.

Historial de precios

Apunta los precios con el tiempo para ver si el producto baja de precio antes de decidir.

Decisiones claras

Marca cada producto como comprado, descartado o pospón la revisión. Nada se borra: todo queda registrado.

Estadísticas

Consulta cuánto has gastado, cuánto has evitado gastar, categorías y tiempos medios de decisión.

Cómo funciona

1

Añades el producto

Con precio, categoría, motivo y prioridad. La app sugiere un periodo de espera según el precio.

2

Esperas

Mientras tanto comparas alternativas, revisas el historial de precios y compruebas si ya tienes algo parecido.

3

Revisas

En la fecha de revisión respondes el cuestionario y puntúas necesidad e interés.

4

Decides

Con la recomendación en la mano: comprar, posponer o descartar. Sin arrepentimientos ni compras por impulso.

Espera sugerida por precio: menos de 15 € → 7 días · menos de 35 € → 15 días · menos de 50 € → 30 días · 50 € o más → 45 días.

Ponerla en marcha

La forma más sencilla es con Docker. Necesitas Docker Desktop (o Docker con Compose) y ejecutar tres comandos: 

# 1. Descarga el proyecto
git clone https://github.com/Marinafabregat/lo-quiero.git
cd lo-quiero

# 2. Construye y arranca (la primera vez tarda unos minutos)
docker compose up --build

# 3. Abre la aplicación
# http://localhost:8000

Las migraciones de la base de datos se aplican automáticamente al arrancar. Tus datos se guardan en la carpeta ./data y sobreviven a docker compose down.

Datos de demostración

Para verla con contenido de ejemplo (productos, revisiones, inventario y el panel de administración con usuario admin): 

docker compose exec web python manage.py seed_demo

Si experimentas y quieres empezar de cero, añade --reset al comando. Cuidado: borra todos los datos.

Panel de administración

Está en http://localhost:8000/admin. Tras ejecutar seed_demo entra con admin / admin. Por ser una app local de un solo usuario se comparte esa contraseña por defecto: cámbiala cuando empieces a usarla. 

docker compose exec web python manage.py changepassword admin

Alternativa sin Docker

Con Python 3.12: crea un entorno virtual, instala las dependencias y lanza el servidor de desarrollo. La configuración genera una clave secreta propia por instalación, así que el repositorio no guarda ninguna. 

python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
